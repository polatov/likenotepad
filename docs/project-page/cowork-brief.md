# Бриф: страница LikeNotepad.exe в блоге polatov.me

Материалы для отдельного чата о блоге. Приложение дорабатывается в другом чате; здесь —
только размещение информации о нём на сайте.

## Кто и что

- Автор: Тимур Полатов, блог **polatov.me** — WordPress, на русском, технический
  (Gentoo, OpenBSD, Python, Git, AI), минималистичный, навигация по тегам, есть RSS.
  Подзаголовок блога: «делю на ноль, обогащаю уран».
- Проект: **LikeNotepad.exe** — простой текстовый редактор для macOS в духе классического
  Блокнота Windows. Слоган (он же текст в окне «О программе»):
  «Тот самый Блокнот, но без Windows. Никаких облаков, подписок и ИИ. Просто текст».
- Версия сейчас: **1.0.0**. Написан на Tauri 2 (Rust + WebKit).

## Что нужно

1. **Страница проекта по адресу `https://polatov.me/notepad/`** — обычная страница
   WordPress с ярлыком (slug) `notepad`. Адрес уже зашит в приложение: в окне
   «О программе» есть ссылка `polatov.me/notepad`, пока страницы нет — она ведёт на 404.
   Поэтому ярлык менять нельзя (или сообщить в чат про приложение, чтобы поменяли ссылку).
2. По желанию — **пост-анонс** в блоге со ссылкой на страницу.

## Что уже готово (в этой папке)

- `page.html` — черновик тела страницы на русском для блока «Произвольный HTML»:
  слоган, скриншот, абзац «зачем», список возможностей, скриншоты поиска и тёмной темы,
  раздел «Скачать» с инструкцией для первого запуска, раздел «Исходный код».
  Абзац «зачем» написан не автором — его стоит переписать своим голосом.
- `notepad-light.png`, `notepad-find.png`, `notepad-font.png` — скриншоты окна с примером
  заметки: главное окно, найденное совпадение, окно выбора шрифта (светлая тема, ~1400 px, PNG с прозрачной тенью — не конвертировать в JPEG, иначе тень станет
  чёрной рамкой).
- `app-icon-1024.png` — иконка приложения, годится как изображение записи / для соцсетей.

## Заглушки и чего пока нет

- **Скачивание:** вышла версия **1.0.0**. Постоянная ссылка на последнюю версию —
  https://github.com/polatov/likenotepad/releases/latest (там `.dmg`, универсальный:
  Apple Silicon + Intel). Через Homebrew: `brew install --cask polatov/tap/likenotepad`.
  Эти ссылки уже вставлены в `page.html`.
- **Исходный код открыт** под MIT: https://github.com/polatov/likenotepad.
- **Приложение не подписано и не нотаризовано** Apple (нужен платный Developer ID), поэтому
  на странице есть инструкция: «Системные настройки» → «Конфиденциальность и
  безопасность» → «Всё равно открыть». Не обещать, что «просто скачай и запусти».
- Минимальная macOS: 10.15 (так поддерживает Tauri 2; на старых системах не проверялось).

## Факты о приложении (для текстов)

- Открывает и сохраняет простой текст: txt, log, md, csv, json, xml, ini, conf, cfg, yaml.
  Сохраняет файл в той же кодировке (UTF-8, UTF-16, Windows-1251) и с теми же переводами
  строк (Windows/Unix/старый Mac), с какими открыл, — как Блокнот.
- Меню и сочетания клавиш как в классическом Блокноте; системные лишние пункты macOS
  (автозаполнение, диктовка, эмодзи, полноэкранный режим) убраны из меню специально.
- Поиск (⌘F) со счётчиком и учётом регистра, «Найти далее» (⌘G), «Заменить»/«Заменить все»,
  «Перейти» к строке, вставка времени/даты, пасхалка `.LOG` (как в Блокноте Windows).
- Перенос по словам, выбор шрифта, строка состояния, светлая/тёмная тема, несколько окон,
  вкладки по желанию, печать, иконка файла в заголовке окна.
- Интерфейс на 8 языках: русский, английский, испанский, немецкий, французский,
  португальский (Бразилия), китайский (упрощённый), японский.
- При первом запуске один раз предлагает (через системный диалог macOS) открывать `.txt`
  по умолчанию.
- Без облаков, аккаунтов, телеметрии и ИИ.

## Ограничения для работы с блогом

- Ничего не публиковать и не менять на живом сайте без явного «да» автора: сначала
  показать черновик.
- Ярлык страницы — `notepad` (см. выше).
- Писать в тоне блога: коротко, по делу, с лёгкой иронией; без маркетинговых штампов.
