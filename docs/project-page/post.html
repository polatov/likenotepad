Вышла версия 1.0 LikeNotepad.exe — простого текстового редактора для macOS в духе классического Блокнота Windows. Никаких облаков, подписок и ИИ. Просто текст.

Зачем

На Mac не нашлось программы, которая делала бы то же, что Блокнот: открыть текстовый файл, поправить пару строк, сохранить и ничего при этом не сломать. TextEdit превращает заметку в RTF, редакторы кода для этого слишком тяжёлые, а приложения для заметок хотят аккаунт. Пришлось написать своё.

Точнее, не совсем написать: это вайбкодинг. Код писал Claude Code, я ставил задачи, придирался и проверял. Так что «никаких ИИ» — это про само приложение, а не про то, как оно появилось.

Что внутри

  • Меню и сочетания клавиш как в Блокноте, лишние системные пункты macOS убраны.
  • Файл сохраняется в той же кодировке (UTF-8, UTF-16, Windows-1251) и с теми же переводами строк, с какими был открыт.
  • Поиск и замена, «Перейти» к строке, перенос по словам, выбор шрифта, светлая и тёмная тема.
  • Работает пасхалка .LOG.
  • Интерфейс на восьми языках.

Полный список — на странице проекта.

Как установить

Скачать .dmg (Apple Silicon и Intel, macOS 10.15 и новее) или через Homebrew:

brew install --cask polatov/tap/likenotepad

Приложение не подписано сертификатом Apple, поэтому первый запуск macOS заблокирует. Открыть: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть». Один раз.

Исходники

Написано на Tauri 2 (Rust + WebKit), код открыт под MIT: github.com/polatov/likenotepad. Ошибки и пожелания — в Issues.
